# 🌐 Indy7 로봇 네트워크 및 통신 설정 가이드

본 가이드는 Indy7 로봇과 PC를 연결하고, Python(IndyDCP3)을 통해 통신을 확립하는 방법을 다룹니다.

## 1. 네트워크 물리적 연결

* **연결 방식**: 로봇 컨트롤 박스(STEP)의 **LAN 포트**와 제어용 PC(랩탑)를 **이더넷(LAN) 케이블**로 직접 연결합니다.
* **공유기 사용 시**: 로봇과 PC가 동일한 공유기(Hub)에 연결되어 있어야 합니다.

---

## 2. PC 네트워크 환경 설정 (가장 중요)

로봇의 IP가 `192.168.1.10`이므로, PC의 IP도 **동일한 대역(`192.168.1.xxx`)**으로 맞춰야 합니다.

1. **제어판 > 네트워크 및 공유 센터 > 어댑터 설정 변경**
2. 이더넷 항목 우클릭 > **속성**
3. **인터넷 프로토콜 버전 4(TCP/IPv4)** 선택 > 속성
4. **다음 IP 주소 사용** 선택 후 아래와 같이 입력:
* **IP 주소**: `192.168.1.100` (10을 제외한 2~254 사이 숫자)
* **서브넷 마스크**: `255.255.255.0`
* **기본 게이트웨이**: `192.168.1.1`



---

## 3. 통신 연결 확인 (Ping Test)

코드를 실행하기 전, 하드웨어적으로 연결되었는지 확인합니다.

1. `Win + R` > `cmd` 입력하여 터미널 실행
2. 아래 명령어 입력:
```bash
ping 192.168.1.10

```


3. **결과 확인**:
* `192.168.1.10(으)로부터의 응답: 바이트=32...`: **연결 성공**
* `요청 시간이 만료되었습니다`: **연결 실패** (케이블 및 IP 설정 재확인 필요)



---

## 4. Python 통신 초기화 코드

Python 라이브러리를 통해 로봇 객체를 생성하고 통신 상태를 확인합니다.

```python
from neuromeka import IndyDCP3

# 로봇의 고정 IP 주소
ROBOT_IP = "192.168.1.10" 

# 1. 인스턴스 생성 (통신 시작)
# index=0은 단일 로봇 연결 시 기본값입니다.
indy = IndyDCP3(robot_ip=ROBOT_IP, index=0)

# 2. 통신 상태 확인
data = indy.get_robot_data()
if data['is_robot_connected']:
    print(f"✅ 로봇({ROBOT_IP}) 연결 성공!")
else:
    print("❌ 로봇과 통신은 되나 하드웨어가 비활성 상태입니다.")

```

## 5. 통신 관련 주요 트러블슈팅

| 문제 상황 | 원인 및 해결 방법 |
| --- | --- |
| **Timeout Error** | PC의 IP 대역이 로봇과 다른 경우 (`192.168.0.xxx` 등 확인) |
| **Connection Refused** | 로봇 컨트롤러 소프트웨어가 실행 중이지 않거나 IP가 충돌하는 경우 |
| **Ping은 가는데 코드는 안됨** | Windows 방화벽이 Python의 포트 접근을 차단하는 경우 (방화벽 일시 해제 권장) |
| **IndyDCP3 모듈 없음** | `pip install neuromeka`를 수행했는지 확인 |

---

## 6. 핵심 제어 함수 (연결 후 사용)

통신이 성공한 후, 아래 함수들을 순서대로 사용하여 로봇을 조작합니다.

1. `indy.recover()`: 에러 상태 해제
2. `indy.set_servo_all(True)`: 모터 브레이크 해제 (통신 연결 필수)
3. `indy.movej([각도들])`: 관절 이동 명령 전송
